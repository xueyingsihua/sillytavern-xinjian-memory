# ✉️ 信笺 | SillyTavern 外置向量记忆库 (RAG)

专为 **SillyTavern（酒馆）** 设计的「信笺」风外置长期记忆库插件（支持 **☀️ 初晴日间 / 🌙 星夜夜间** 双配色一键切换）。  
保留 **本地存储（大众零门槛开箱即用）** 与 **GitHub 私人仓库（跨设备云端同步 / 支持与外部记忆库互通）** 两种存储系统，支持**按聊天分支自动分隔间存储**以及**玩家随时手动改隔间名 / 绑定共用隔间**。

---

## ✨ 核心特性

### 1. 双存储系统（自由切换 / 支持迁移）
- **💾 本地存储模式（默认开启，适合大众）**：
  - 使用浏览器原生 **IndexedDB** 储存记忆切片与高维向量，突破 `localStorage` 5MB 上限，无需配置 GitHub、零门槛安装即用。
  - 支持单隔间 **JSON 导出 / 导入** 备份，格式与 GitHub 仓库模式完全兼容。
- **☁️ GitHub 私人仓库模式**：
  - 使用你自己的 GitHub 私有仓库 + PAT（`repo` 权限）同步云端，并**默认开启独立目录物理隔离 (`tavern/`)**：
    - **🛡️ 酒馆独立子目录（默认推荐）**：数据全部保存在 `tavern/global_profile.json` 与 `tavern/branches/{隔间名}.json` 下。即使你用同一个私人仓库存放了其他网页版/外部记忆库数据（位于根目录 `branches/`），也**绝不会把那边的数据抓进酒馆，更不会覆盖根目录 `branches/` 原文件**；如需借用根目录的某个隔间，可在「🌿 隔间与分支总管」里按需**单向克隆**到酒馆。
    - **🔗 与仓库根目录共用（高级可选）**：仅在需要与其他基于同一仓库根目录的应用实时双向共享隔间时，才在设置中手动切换回根目录 `branches/`。
  - 内置无损合并保护（Merge-Before-Write）：首次同步或手动将本地记忆推送至 GitHub 时，会先检查云端同名隔间并按 ID 去重合并，防止意外覆盖云端已有记忆。

### 2. 智能记忆隔间：默认跟分支走 + 随时手动改名
- **默认自动隔离**：切换酒馆聊天或新建分支（Branch）时，自动监听 `CHAT_CHANGED` 并按当前聊天分支名建立独立记忆隔间，不同时间线、不同分支之间 **100% 物理隔离不串戏**；在酒馆内基于当前聊天新建分支时，新分支也会自动获得自己的新默认隔间，不会误覆盖原线记忆。
- **支持手动改隔间名 & 共用绑定**：
  - 点面板中的 **「✏️ 改名」**，可将默认的一长串时间线文件名重命名为好记的名字（如 `初晴_主线`），并自动将已有记忆迁移过去；
  - 也可以选择 **「🔗 仅切换/绑定」**，让多个聊天分支共用同一个记忆隔间；
  - 随时可点 **「↩️ 恢复默认分支名」** 退回自动跟随模式。

### 3. 顶部下拉全景页 + 随行悬浮速控窗 + `@D0` 深度层直注
- **顶部栏原生下拉全景页**：点击酒馆顶部导航栏里的 **✉️ 信封图标**（或扩展菜单 / 扩展页按钮）即可从顶部拉下完整「信笺记忆库」全景页，涵盖「📚 记忆档案库」「🌿 隔间与分支总管」「⚙️ 存储、模型与深度配置」三大分页，顶部支持一键切换 **☀️ 初晴（日间）/ 🌙 星夜（夜间）** 配色。
- **随行精简悬浮速控窗**：画面上的「✉️ 信笺」悬浮球可自由拖动，展开后的速控小窗会自动跟随悬浮球位置弹出（只保留改隔间名、快速抓取总结存储、唤醒挂载深度层）。
- **深度层直注 (`chuqingMemoryInterceptor`，默认 `@D0`)**：
  - 唤醒记忆不再写入输入框，而是直接通过 `setExtensionPrompt` 挂载到设定的提示词深度层（默认 `@Depth = 0 · System`，贴近末尾发送，不破坏前面长对话的 KV Cache 缓存前缀）。
  - 开启 **「🔮 发消息时自动扫最近 N 楼唤醒注入」**（默认扫描最近 4 楼正文，可在 ⚙️ 配置中设为 1~12 楼）后，每次发送消息都会自动提取近期楼层清洗后的正文去匹配切片，直接挂载到 `@D0` 随请求发送；
  - 下方「唤醒挂载」为**半自动模式**：填入关键词可按词精准唤醒，**留空直接点「🔮 唤醒挂载」** 同样会自动扫描最近 N 楼正文预挂载到深度层。
- **一键抓取与自适应多切片归档**：
  - 默认优先抓取 **「✨ 未归档新楼层」**（自动记录上次归档楼层游标，避免与手动或自动归档重复总结），也支持「最近 5 轮 / 10 轮」或「指定楼层范围」，默认仅提取 `<content>` 正文标签（无该标签时保留玩家原文防漏抓），并自动剥离 `<think>`、`<thinking>`、`<status>`、`小剧场`、`options` 等无关预设组件与思维链；
  - 跨越较多楼层（如 10~30+ 层）或长剧情时，AI 会按事件转折与关键细节**自动拆分为多条 100~220 字独立记忆切片**，并为每条切片分别匹配标题与 `#标签`（标签选择区支持一键快速加标签），不遗漏中间伏笔；总结使用的全局提示词已在 **⚙️ 配置** 面板开放可视化编辑，支持自定义与一键 **「↩️ 恢复默认提示词」**；
  - 支持一键开关「清洗 HTML 注释自检块 (`<!-- ... -->`)」，并提供「保留注释关键词白名单」（直接写注释里的关键词即可，无需加 `<!-- -->`，如保留含 `伏笔` 的注释而过滤 `<!-- 文中自检... -->`）；所有抽取与清洗规则可自由增删改、另存为多套预设模板并在全景页/悬浮速控窗一键切换。
  - 支持开启 **「每 N 轮自动存」（默认每 10 轮）**，在后台增量总结未归档的新楼层存入当前隔间，与手动归档协同不重叠。
- **零 Key 也能先用**：
  - 摘要接口支持 **Google Gemini**、**硅基流动 SiliconFlow**、**通用 OpenAI 反代 (`/v1`)**，以及 **🍺 直接复用酒馆当前主 API**；
  - 向量接口支持拆分独立配置（如总结用 Gemini/酒馆 API，向量与 Rerank 用硅基流动免费 `BAAI/bge-m3`），未填向量 Key 时自动启用 **128 维本地特征向量** 兜底。

## 📦 从仓库直接安装（SillyTavern 推荐方式）

1. 将本插件文件夹里的全部文件（`manifest.json`、`index.js`、`style.css`、`README.md`）放到一个 GitHub 仓库的**根目录**下（例如 `https://github.com/你的用户名/sillytavern-chuqing-memory`）。
2. 打开 SillyTavern 顶部菜单 **扩展 (Extensions)** $\rightarrow$ **安装扩展 (Install extension)**。
3. 粘贴你的仓库地址，点击 **Save / 安装**。
4. 安装完成后刷新页面，你可以通过以下任意入口打开：
   - **酒馆顶部导航栏** 的 **✉️ 信封图标**（直接拉下全景记忆库页面）；
   - 画面上的 **「✉️ 信笺」随行悬浮球**（可按住拖动，小窗跟随球体弹出精简速控功能）；
   - 输入框左侧魔法棒菜单（`Extensions`）里的 **「信笺记忆全景页」**；
   - **扩展**设置面板中的 **「✉️ 信笺 | 外置向量记忆库」** 折叠抽屉。

> **离线/本地手动安装**：也可以直接将本文件夹整体复制到 SillyTavern 目录下的 `public/scripts/extensions/third-party/sillytavern-chuqing-memory/`，然后刷新浏览器即可。

## ⚙️ 快速上手

1. **大众本地开箱即用**：
   - 安装后默认即为 **💾 本地存储模式**；
   - 若不想额外申请接口 Key，在 **⚙️ 配置** 中将「AI 摘要提炼接口」设为 **🍺 复用酒馆当前主 API**、向量接口设为 **🧩 纯本地特征向量**（或共用）即可立即使用！
   - 若想获得最佳语义检索精度，推荐在「向量接口」单独填一个免费的 **硅基流动 (`BAAI/bge-m3`)** 或 **Google Gemini (`text-embedding-004`)** Key。
2. **开启 GitHub 私人仓库云端同步（可选）**：
   - 在 **⚙️ 配置** 中将「记忆库存储系统」切换为 **☁️ GitHub 私人仓库模式**；
   - 目录隔离模式保持默认的 **🛡️ 酒馆独立子目录 (`tavern/`)**（哪怕复用已有记忆仓库，两边数据也彻底隔离互不干扰）；
   - 填入 `ghp_...` 开头的 GitHub Token（需勾选 `repo` 权限）与私有仓库名（格式 `用户名/仓库名`）；
   - 点击 **「🔌 测试并同步目录」** 即可拉取/初始化 `tavern/global_profile.json` 与 `tavern/branches/` 目录。
3. **修改隔间名**：
   - 展开悬浮面板，在「🌿 当前记忆隔间」卡片点击 **「✏️ 改名」**：
     - 填入新名字点 **「✏️ 重命名并迁移」**：把当前默认分支名隔间直接改名并搬走记忆；
     - 点 **「🔗 仅切换/绑定」**：让当前聊天指向另一个已有隔间（如共用某条线的记忆）；
     - 点 **「↩️ 恢复默认分支名」**：重新自动跟随酒馆聊天分支名。
